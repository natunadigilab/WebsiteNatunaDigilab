# Natuna Digilab

Open-source design system website built with Next.js, TypeScript, and Tailwind CSS.

## Getting started

```bash
npm install
npm run dev
```

## Structure

- `src/app` — pages (Home, Components, Templates, Docs, Themes)
- `src/components` — shared UI (Header, Sidebar, previews)
- `src/lib/components-data.ts` — component metadata/content
